# Week 1 — Project Introduction and Setup

## Goals

- Understand the overall project and what you will build.
- Set up your development environment.
- Create the GitHub repository structure.
- Review the BOM and order parts.

## Tasks

1. **Read project overview**
   - Read `README.md` carefully.
   - Skim `BOM.md` and `BUILD_PLAN.md` to understand the big picture.

2. **Set up tools**
   - Install the Nuvoton toolchain and IDE (Keil, IAR, or other supported environment).
   - Install Nu-Link2 drivers for the NuMaker-M258KG.
   - Install Git and create a GitHub account if you don’t have one.

3. **Create the repository**
   - Create a new GitHub repo (e.g., `robotic-hand-project`).
   - Clone it locally.
   - Add the initial files: `README.md`, `BOM.md`, `BUILD_PLAN.md`.

4. **Review hardware**
   - Confirm you have or can order:
     - NuMaker-M258KG.
     - Amazing Hand kit.
     - Feetech SCS0009 servos.
     - Power supply and basic electronics.
   - Note any missing parts or tools.

## Deliverables

- A GitHub repo with:
  - `README.md`
  - `BOM.md`
  - `BUILD_PLAN.md`
- A short note (in `docs/notes.md` or similar) describing:
  - Your current tool setup.
  - Any parts you still need to order.

## Time Estimate

- 4–6 hours total.

---

## Self-check

- Can you explain in your own words what the project will do?
- Is your IDE and debugger installed and working?
- Is your GitHub repo visible and structured as in `README.md`?
