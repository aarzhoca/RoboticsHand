# Week 2 — Design Study and First Prints

## Goals

- Understand the mechanical design of the Amazing Hand.
- Prepare for 3D printing (or unpack the kit if pre-printed).
- Start assembling one finger as a test.

## Tasks

1. **Study the hand design**
   - Open the Amazing Hand GitHub repo and documentation.
   - Identify:
     - Finger parts.
     - Palm and wrist parts.
     - Servo mounting locations.
   - Read the assembly guide if available.

2. **3D printing (if applicable)**
   - If you are printing yourself:
     - Slice one finger set first (not the whole hand).
     - Use recommended layer height and infill.
     - Print supports if needed.
   - If you have a kit:
     - Identify and organize the finger parts.

3. **Test assembly**
   - Assemble one finger mechanically.
   - Check joint movement and fit.
   - Note any adjustments needed (sandpaper, re-print, etc.).

4. **Update your repo**
   - Add a short note in `docs/notes.md`:
     - What you printed or unpacked.
     - Any issues or observations.

## Deliverables

- One fully assembled test finger.
- Notes on print settings or kit parts.
- Updated repo with your notes.

## Time Estimate

- 6–8 hours total.

---

## Self-check

- Does the test finger move smoothly?
- Do you understand how tendons or linkages will work?
- Are you ready to print or assemble the rest of the hand next week?
